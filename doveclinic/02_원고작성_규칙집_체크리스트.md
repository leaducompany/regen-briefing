## C. 의학 정확도 — 원장님이 교정한 사실

- **색소 레이저 토닝 간격**: 일반적으로 **2주** (12주 아님)
- **기미 토닝**: 보통 1064nm Nd:YAG → "짧은 파장" 아님. "짧은 시간(나노초·피코초) 동안 에너지를 집중"
- **색소 치료 원리**: "세포소기관 단위 선택적 광열분해" 쓰지 말 것 → "세포는 살려둔 채 색소만 선택적으로 파괴"
- **저색소**: "하얀 잔점", "반점형 저색소증" → "백반증과 같은 하얀 반점", "하얀 반점과 같은 저색소증"
- **주근깨 롱펄스**: 넓은 스팟으로 표면 색소를 균일하게 가열 → 얼굴 전체에 퍼진 경우 빠르게 치료하기 유리
- **쥐젖**: 원인은 단정하지 말고 복합 요인(마찰, 유전, 호르몬, 인슐린 저항성)으로. 비만·인슐린 저항성은 "연관", "직접 만든다고 단정 못 함". 딱지는 1~2주. 재발은 "완전히 제거되면 흔하지 않음, 새 병변은 생길 수 있음". 본원 = CO₂ 레이저 + 듀오덤
- **지루각화증(검버섯)**: 모양은 다양함. 치료는 냉동, 소파, 전기소작, 레이저 중 선택하고 본원은 대부분 CO₂
- **한관종**: 진피까지 다뤄야 함 → CO₂로 단계적 제거 + 니들RF(버츄)로 위축. 눈밑처럼 흉터 잘 남는 부위엔 니들RF가 유리
- **눈밑꺼짐**: 필러가 "푸르스름하게 비칠 수 있음". 눈밑과 앞볼은 **한 몸** (포물선처럼 이어지는 게 예쁨). 눈밑 안색(비염, 비비는 습관, 화장) → 토닝·리쥬란. 잔주름 → 스킨보톡스·리쥬란·버츄
- **아이써마지**: 눈밑·눈가만 할 땐 아이실드 없이, 윗눈꺼풀 할 땐 아이실드 착용. 샷은 균일 배분 X → 눈썹 아래~쌍꺼풀 라인에 집중. 하안검은 부기 때문에 출력·밀도 조절. 주의사항(당일 레티놀 자제, 자외선 차단), 유지기간, 간격 필수
- **울쎄라피 프라임**: 깊이가 다른 팁 조합(진피 상층~SMAS)으로 층별 설계. "볼패임 걱정" Q&A 필수 (가능하지만 범위·강도 조절, 볼륨 시술과 순서 계획). 통증과 마취 방법(크림, 신경 차단), 붓기·뻐근함, 수개월에 걸친 변화, 반복 주기 필수. White 2007 인용 시 "이전 세대 장비 연구" 명시
- **마운자로**: "용량이 높아질수록 감량 폭이 조금씩 커지는 경우가 일반적". 체성분 분석 기반 처방이 도브의 방식
- **스킨보톡스**: 기전(SNAP-25)만 쓰고 끝내지 말 것. 부위, 주입 간격, 마취 크림, 시술 후 주의사항 필수
- **리투오파인**: 캐뉼라 vs 바늘 차이 (환자 문의 많음). 원장님은 눈밑에 캐뉼라 + 진피내 주사를 함께 시행
- **여드름 용어 풀이**: 각질 용해 성분 → 각질을 녹이는 성분 / 면포 → "면포(좁쌀여드름)" / 구진·농포 → 붉게 부어오른 여드름, 고름 찬 여드름 / 결절·낭포 → 피부 속에서 딱딱하게 만져지는 깊은 여드름 / 국소 레티노이드(아다팔렌·트레티노인) → 처방이 필요한 바르는 비타민A 유래 연고 / 국소 항생제 → 바르는 항생제 / 이소트레티노인(이소티논, 로아큐탄 등) 병기 / "병변" 반복 금지

## D. 문체·구성 원칙 ("도브 스타일")

1. **진료실 대화체**: 환자의 실제 질문으로 시작 → "결론부터 말씀드리면"
2. **3줄 요약 또는 원장님 한마디 박스**를 글 앞이나 끝에 (9/16)
3. 쉬운 말 우선. 전문용어는 처음 나올 때 한 번 풀어쓰기
4. "~인데요 / ~죠" 연속 3회 금지. 문장 길이에 변화 주기
5. 원장님 1인칭 임상 경험을 최소 1문단 ("진료실에서 가장 많이 받는 질문은…", "실제로 저희는…")
6. **불안은 낮추고 행동은 분명하게**: 겁주는 경고보다 "이럴 땐 이렇게 하세요"
7. 논문은 1~2개. **연구 종류, 대상, 한계**를 한 줄로. 타 시술·타 제품 연구를 도브 제품과 "같다"고 쓰지 않기
8. 시술 글이면 **기본 정보 블록 필수**: 대상 / 과정·마취 / 통증 / 다운타임 / 효과 시점 / 유지·간격 / 주의사항
9. 도브의원 고유 요소를 1~2개 (Eve Muse AI 진단, 체성분 분석, 캐뉼라 선택 기준, 듀오덤, CO₂ + 버츄 병행 등)
10. 마무리는 명언형 한 줄 (예: 원장님 쓰레드 "약은 출발선을 앞당겨줄 뿐, 결승선까지 가는 건 결국 습관입니다")
11. **도입은 상황·공감 장면으로** (원장님 원고: "소개팅 전날, 중요한 발표를 앞둔 주말, 결혼식 2주 전—", "친구들 사이에서 놀림을 받아 본 기억")
12. **이모티콘과 친근한 이미지를 중간중간 넣기** (원장님이 원고 안에 직접 메모로 두 번 요청함, 8/25)
13. **원장님 개인 에피소드 넣기** ("저도 결혼식 1달 전 와이프한테 해주고, 직접 셀프로 했던 시술", "보통 저도 콧대 2줄, 비주 2줄 추천") → 주제마다 원장님께 한 줄 받기

### G-2. 진료 철학 (원고마다 1문장 이상 녹이기)
- **원장 선상담 원칙** (원장이 먼저 상담하고, 실장님은 그 결과를 바탕으로 상담)
- **시술을 과하게 권하지 않음**: "여기는 원장님이 시술하지 말라 한다는 얘기도 자주 듣습니다. 그걸로 실장님에게 가끔 혼나기도 하고요"
- 치료 순서: **상담 → 생활습관 교정 → 약 처방 → 시술 → 수술**
- 매 회차마다 경과를 묻고, 궁금한 점이 없었는지 확인
- 환자가 자발적으로 다시 찾는 병원 / 낸 돈 이상의 만족 / 한 분 한 분께 집중하는 개인의원
- **지양**: 최저가 경쟁, 별점 나열 같은 "병원 쇼핑"을 떠올리게 하는 콘텐츠

### G-3. 원장님 인터뷰 속 실제 사실 (원고에 그대로 쓸 수 있음)
- 7층 확장 콘셉트: **리쥬란·쥬베룩 스킨부스터 센터 + 글로벌 병원** / 주력: 리쥬란, 쥬베룩 / 부주력으로 키울 시술: **실리프팅**
- 1mm 리쥬란: 상부 진피에 일정량의 bleb을 촘촘하게. 리쥬란힐러 통증 NRS 7~8, 리쥬란HB 3~4
- 통증 관리: 마취크림 래핑 + 초음파 침투모드, 필요하면 진통 수액, 잡는 인형, 중간중간 통증 체크
- 티타늄: 재생 작용은 최대 6개월, 시술 20~30분, 30~40대 여성에게 특히 잘 맞음, 결혼 전 등 행사 전에 좋음
- 실리프팅: 끌어올리는 효과 3~4개월, 콜라겐 재생 6~12개월. **60대에 피부가 얇고 볼륨이 없는 분은 울퉁불퉁해질 위험**이 있어 적응증 선별이 중요
- 마운자로/위고비: 매달 인바디 / 위장관 부작용으로 중단하는 비율은 원장님 경험상 **1~2%** / 투약 방법 오류나 잦은 음주가 원인인 경우가 많음 → 재교육, 낮은 용량 오래 유지, 보조약 / "**우열을 가리는 약이 아니다**, 6개월~1년 평균 10~20% 감량" / 정서적 지지
- 실제 환자 사례: 결혼 4일 전 옆볼 울트라콜을 원한 20대 후반 신부 → 울트라콜은 결과가 나오기까지 시간이 걸려서 **옆볼 필러 2cc를 권해드렸고 만족하셨음** / 경남 진주에서 매년 오시는 50대 환자분들
- 환자층: 20~60대, 남성 20~30%, 외국인 매출 약 30%, 단골과 소개 환자 많음
- 진료량: 대면 20~30건/일, 비대면 5~10건/일 (반복처방 위주)

### G-4. 키워드 운영 기준 (키워드리스트.xlsx)

### I-3. ⚠️ 마크다운 기호 `**` 금지 (9/29 담당자 지적)
- 담당자가 1편 수정본에서 원고 속 **`**` 기호를 일부러 모두 삭제**함.

### I-5. "수술" 표현 주의 (9/30 담당자 지적)
- 도브의원은 **수술을 하지 않는 클리닉**입니다. "원내에서 수술 과정을 거친다"처럼 읽히는 문장은 쓰지 않습니다.
